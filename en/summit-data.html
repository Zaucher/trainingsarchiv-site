Summit data

The peak list from Spurlog as a download

For ski tours, hikes and trail runs, Spurlog suggests a name based on the highest summit reached, for example “Ski tour Hochgern”. For this the app carries a peak list from OpenStreetMap, so that it works without a connection. You can download exactly this list here.

spurlog-gipfel-1.2.zip · 1.8 MB · matches Spurlog 1.2
117,129 named peaks, roughly 43–51° north and 5–17° east. A table (tab-separated, UTF-8) with latitude, longitude, name and elevation in meters, plus a license text and a description of how the list was made. The archive contains an English LICENSE.txt.

How the list was made

All points tagged natural=peak with a name were queried through the Overpass API. Elevations given in feet were converted, implausible values discarded and duplicate entries with the same name at almost the same place merged. The details are in the file LIZENZ.txt in the download.

Is a summit missing or a name wrong? Then it can be corrected directly in OpenStreetMap and will reach the app with a later version.
